# Headline Formulas for Case Studies

These formulas help generate compelling hero headlines that lead with impact.
Read this file when you need inspiration for crafting the case study headline.

## Formula Patterns

### The Transformation Pattern
"How [action/redesign] [metric/outcome] for [audience size]"
- "How a reimagined onboarding flow cut time-to-value by 60% for 5,000+ enterprise teams"
- "How contextual search replaced a 12-step workflow for logistics operators"

### The Problem-Killed Pattern
"Eliminating [pain point] for [audience] through [approach]"
- "Eliminating the spreadsheet workaround that cost operations teams 4 hours per week"
- "Ending alert fatigue for 800+ on-call engineers with intelligent notification grouping"

### The Scale Pattern
"Designing [feature] that [outcome] at [scale]"
- "Designing a permissions system trusted by 500+ enterprise accounts"
- "Designing collaborative workflows that handle 10,000+ daily active sessions"

### The Unlock Pattern
"Unlocking [capability] for [audience] by [approach]"
- "Unlocking self-serve analytics for non-technical teams through a visual query builder"
- "Unlocking real-time collaboration for remote compliance teams"

## Headlines to Avoid

- Starting with "Redesigning..." or "Designing..." (buries the impact)
- Using the product name first without context (means nothing to outside readers)
- Being vague: "Improving the User Experience" (says nothing specific)
- Being too long: Keep it under 20 words
- Using jargon: "Leveraging AI-driven insights..." (speak plainly)

## Subtitle Format

Always follow the headline with:
**[Product Name] — [Your Role Title] — [Year]**

Example: "DataPulse Analytics — Product Designer — 2025"

If the product is well-known, lean into it. If not, a brief descriptor helps:
"Meridian (enterprise logistics platform) — Product Designer — 2024"
